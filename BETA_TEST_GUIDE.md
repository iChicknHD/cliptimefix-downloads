# Beta Test Guide

This is a free, experimental Windows x64 beta. We are looking for testers with a real GoPro and Lightroom Classic.

1. Keep camera originals unchanged. Make a separate working copy of a short, non-sensitive clip.
2. Extract the ZIP, preserving its folder structure, and run `ClipTimeFix.exe` from the extracted folder.
3. Start with MP4. MOV is in implemented scope but runtime behavior is not verified.
4. Review the proposed result. Import only the generated copy into Lightroom Classic.
5. Compare the original and output. Keep backups; do not delete the source based on this test.

The application works locally; no cloud processing or telemetry is part of the implemented workflow. Do not publicly upload private videos. Do not send private camera originals. Share feedback about camera model, container, Windows version, Lightroom Classic version, observed timestamps, and whether the original stayed unchanged. Remove personal details from screenshots.

HERO11 core behavior was tested with a real video. HERO10/12/13, MOV runtime, packaged GUI interaction, and Lightroom Classic behavior have not been verified. No success is guaranteed.
